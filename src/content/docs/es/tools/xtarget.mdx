---
title: xtarget
description: Biblioteca y CLI para normalización de target triples y mapeo de metadatos entre toolchains.
---

**Repositorio:** [cross-toolchains/xtarget](https://github.com/cross-toolchains/xtarget)

`xtarget` es la base Layer 0 construida sobre [`target-lexicon`](https://crates.io/crates/target-lexicon). Normaliza target triples de Rust, LLVM/Clang, GNU/GCC y Zig (incluyendo calificadores como `.2.31`, `android24` e `ios16.0`) en un único `Target` y deriva bajo demanda las proyecciones para cada ecosistema.

## CLI

```console
$ xtarget host
aarch64-apple-darwin

$ xtarget get llvm-triple riscv64-linux-gnu
riscv64-unknown-linux-gnu

$ xtarget get python-tag x86_64-linux-gnu.2.31
manylinux_2_31_x86_64

$ xtarget env --format github-output aarch64-apple-darwin
triple=aarch64-apple-darwin
os=macos
apple_sdk=MacOSX
apple_arch=arm64
oci_platform=darwin/arm64
```

## Biblioteca Rust

```toml
[dependencies]
xtarget = { version = "0.1", default-features = false }
```

```rust
use xtarget::{Libc, Target, TargetOs};

let target = Target::parse("riscv64-linux-gnu")?;
assert_eq!(target.os(), TargetOs::Linux);
assert_eq!(target.libc(), Libc::Glibc);
assert_eq!(target.llvm_triple(), "riscv64-unknown-linux-gnu");
```
