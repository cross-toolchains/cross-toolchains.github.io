**Repository:** [cross-toolchains/xtarget](https://github.com/cross-toolchains/xtarget) · **Status:** Live on crates.io (`v0.1.0`)

`xtarget` is the Layer 0 target normalization foundation built on [`target-lexicon`](https://crates.io/crates/target-lexicon). It parses Rust, LLVM/Clang, GNU/GCC, and Zig target triples (plus version qualifiers like `.2.31`, `android24`, and `ios16.0`) into a single `Target` value and derives toolchain-specific projections on demand — verified against `rustc --print cfg` across all 331 built-in Rust targets.

## Command Line

```console
$ xtarget host
aarch64-apple-darwin

$ xtarget get llvm-triple riscv64-linux-gnu
riscv64-unknown-linux-gnu

$ xtarget get clang-args riscv64-linux-gnu
-march=rv64gc -mabi=lp64d

$ xtarget get python-tag x86_64-linux-gnu.2.31
manylinux_2_31_x86_64

$ xtarget env --format github-output aarch64-apple-darwin
triple=aarch64-apple-darwin
os=macos
apple_sdk=MacOSX
apple_arch=arm64
oci_platform=darwin/arm64
```

## Rust Library

```toml
[dependencies]
xtarget = { version = "0.1", default-features = false }
```

```rust
use std::process::Command;
use xtarget::{Libc, Target, TargetOs};

let target = Target::parse("riscv64-linux-gnu")?;

match (target.os(), target.libc()) {
    (TargetOs::Linux, Libc::Glibc) => println!("Debian arch: {:?}", target.debian_arch()),
    (TargetOs::Linux, Libc::Musl) => println!("Alpine arch: {:?}", target.alpine_arch()),
    (TargetOs::Windows, Libc::Msvc) => println!("MSVC arch: {:?}", target.msvc_arch()),
    _ => {}
}

Command::new("clang")
    .arg("--target").arg(target.llvm_triple().as_ref())
    .args(target.clang_extra_args());

let cfg = target.rust_cfg();
println!("arch={} os={} env={}", cfg.arch, cfg.os, cfg.env);
```

## Covered Projections

| Group | Methods on `Target` |
|---|---|
| **Core** | `parse`, `parse_loose`, `from_triple`, `host`, `as_str`, `lexicon`, `qualifier` |
| **Platform & ABI** | `os`, `libc`, `endian`, `pointer_width`, `windows_abi`, `wasm_abi`, `apple_sdk`, `is_*`, `exe_suffix`, `dylib_suffix`, `staticlib_suffix` |
| **Toolchains** | `rust_triple`, `rust_cfg`, `llvm_triple`, `clang_extra_args`, `gnu_triple`, `ziglang_triple`, `lld_flavor`, `cargo_env_suffix`, `cc_rs_env_suffix`, `cmake_system_name`, `cmake_system_processor` |
| **Distros & SDKs** | `debian_arch`, `alpine_arch`, `msvc_arch`, `apple_arch`, `android_abi`, `ohos_abi` |
| **Ecosystems** | `node_platform`/`arch`, `python_platform_tag`, `golang_os`/`arch`, `jvm_os`/`arch`/`classifier`, `dotnet_rid`, `kotlin_native_target`, `dart_os`/`arch`, `ruby_platform`, `luajit_os`/`arch`, `oci_platform` |
